# Frozen Test Sets (T5, TB, TM)

These manifests are generated by `frozen_test_sets.py` so **all models** are evaluated on the **same three test sets**, making results comparable.

| Set | Description |
|-----|-------------|
| **T5** | 5-class-only test (from `oral_cavity_5class_dataset/test/`). Binary view: OCA+OPMD=1, Benign+Healthy=0; Unknown excluded for binary metrics. |
| **TB** | Binary-only test (fixed 15% holdout from `oral_cavity_binary_dataset`). Never used for training. |
| **TM** | Mixed merged test = T5 (binary-eligible) ∪ TB. Source field `A` (5-class) or `B` (binary) for per-source metrics. |

**Why this matters**

- **T5** = in-distribution for 5-class models; baseline “same dataset” performance.
- **TB** = in-distribution for binary-only data; shows performance on the other source.
- **TM** = mixed; **TM per-source (A vs B)** shows whether the main issue is “model can’t learn signal” vs “model doesn’t transfer across sources”.

Regenerate manifests (e.g. after changing paths or seed) by running from the `notebooks` directory **with the project venv** (e.g. `venv_multihead_tflite` or whichever has `sklearn` and `tensorflow`):

```bash
python frozen_test_sets.py
```

Or from Python (in a kernel/venv that has `sklearn`): `from frozen_test_sets import build_and_save_frozen_sets; build_and_save_frozen_sets(...)`.
